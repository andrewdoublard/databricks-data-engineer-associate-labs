# databricks-data-engineer-associate-labs
Exercises and projects exploring data engineering on Databricks while preparing for the Data Engineer Associate exam.

This repository contains exercises and projects I completed while learning the Databricks platform and preparing for the Databricks Data Engineer Associate certification.

The aim is to build practical experience working with data pipelines, transformations and storage in a lakehouse environment.

Most of the notebooks come from labs or courses, but the implementations and notes are my own.
